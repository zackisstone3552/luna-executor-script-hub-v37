## Overview

Luna Executor is a Windows desktop application for running Roblox Lua scripts locally on Windows 10 and Windows 11. Its compact layout provides direct access to execution controls, the integrated script hub, and update functionality without adding unnecessary interface complexity.

The executor is intended for common scripting tasks and includes tools for running scripts individually or in groups. It also provides a built-in debugger, SQLite-backed queue persistence, automatic updates, and a workflow that does not require a key.

---

## Included Capabilities

- Start scripts quickly through one-click execution
- Browse more than 500 entries in the built-in Roblox script hub
- Use a compact desktop UI designed for straightforward navigation
- Run the application without an additional key or activation step
- Receive support for automatic application updates
- Preserve queued script sessions in local SQLite storage
- Execute several scripts together through batch execution
- Inspect script behavior with the integrated debugger

## Frequently Asked Questions

**Which operating systems are supported?**  
Luna Executor is intended for desktop use on Windows 10 and Windows 11.

**Does the application support automatic updates?**  
Yes. Auto-update support is included so the application can check for newer builds as they become available.

**What does Luna Executor provide beyond a regular script hub?**  
It brings execution controls, a 500+ entry script hub, batch execution, and debugging functionality together in one desktop application.

**Could using it put my Roblox account at risk?**  
Third-party scripting tools may involve account-related risks. Check Roblox's terms and decide whether to use the software at your own discretion.

**Is data saved on the local computer?**  
Yes. The application includes persistent queue storage, with SQLite used for saved queue data.
